void cleanSemaphore_Client ( sem_t * semaphore)

Closes a semaphore without unlinking it (client side).

Calls sem_close(3) only, since the server or other clients may still hold the semaphore open.

Parameters
semaphorePointer to the semaphore, as returned by semaphore_Client.

◆ cleanSharedMemory_Client()

void cleanSharedMemory_Client ( struct shm * shm,
int shmfd )

Unmaps and closes the shared memory segment (client side).

Calls munmap(2) and close(2). Does NOT unlink the segment, since the server or other clients may still be using it. After this call, shm points to invalid memory and must not be dereferenced.

Parameters
shmPointer to the shared memory, as returned by sharedMemory_Client.
shmfdThe file descriptor returned via sharedMemory_Client's shmfd param.

◆ cleanSharedMemory_Server()

void cleanSharedMemory_Server ( struct shm * shm,
int shmfd )

Unmaps, closes, and unlinks the shared memory segment (server side).

Calls munmap(2), close(2), and shm_unlink(3), in that order. After this call, shm points to invalid memory and must not be dereferenced.

Parameters
shmPointer to the shared memory, as returned by initializeSharedMemory_Server.
shmfdThe file descriptor returned via initializeSharedMemory_Server's shmfd param.

Creates and initializes a named semaphore (server side).

Calls sem_open(3) with O_CREAT | O_EXCL and the given initial value. Terminates the program with EXIT_FAILURE and prints the corresponding error message on failure.

Parameters
sem_nameThe semaphore's name, as used by sem_open(3); see sem_overview(7) for naming rules.

◆ sharedMemory_Client()

struct shm * sharedMemory_Client ( int * shmfd)

Opens and maps an existing shared memory segment (client side).

Calls shm_open(3) without O_CREAT, and mmap(2) to map the segment created by a server. Terminates the program with EXIT_FAILURE and prints the corresponding error message if any of these calls fail.

Parameters
shmfdPointer to an int that will receive the shared memory file descriptor. Caller must keep it for cleanSharedMemory_Client.
Returns
struct shm*

◆ sharedMemory_Server()

struct shm * sharedMemory_Server ( int * shmfd)

Creates and maps the shared memory segment (server side).

Calls shm_open(3) with O_CREAT | O_EXCL, ftruncate(2) to size it, and mmap(2) to map it into the process's address space. Terminates the program with EXIT_FAILURE and prints the corresponding error message if any of these calls fail.

Parameters
shmfdPointer to an int that will receive the shared memory file descriptor. Caller must keep it for cleanSharedMemory_Server.
Returns
